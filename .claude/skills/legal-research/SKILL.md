# /legal-research {사건폴더명}

이후 모든 서면의 인용은 이 산출물에서만 나올 수 있다(인용 단일 진입로).
표기 규칙: `규칙/인용규칙.md`.

## 절차 (쟁점마다 반복)

1. `사건/{사건폴더명}/사건컨텍스트.json`의 `쟁점[]`을 읽는다. 쟁점이 비어 있으면
   /case-intake 먼저 하라고 안내 후 중단.
2. **조문 탐색.** 쟁점 키워드 2~3조합으로 Grep (`path: legalize-kr/kr`).
   후보 법령 파일을 Read로 열어 해당 조문 원문을 직접 확인한다.
3. **현행성 확인.**
   `git -C legalize-kr log -1 --format=%ad --date=short -- "kr/{법령}/{파일}.md"`
   로 최종 개정 일자를 확인하고 출처 핀에 기록.
4. **판례 탐색.** Grep (`path: precedent-kr/민사`, 쟁점에 따라 일반행정 등 추가).
   후보 파일을 Read로 열어 판시사항·판결요지를 직접 읽고, 쟁점과 실제로 맞는지
   판단한다. 키워드만 겹치고 법리가 다른 판례는 버린다. 대법원 판례 우선.
5. **발췌.** 조문은 해당 조 전체, 판례는 판시사항/판결요지의 해당 부분을
   그대로 blockquote로 발췌한다.

## 산출: `사건/{사건폴더명}/리서치/쟁점별_법리.md`

쟁점별 섹션 형식:

    ## 쟁점1: {제목}

    ### 적용 조문
    > 제27조(해고사유 등의 서면통지) ① 사용자는 … (원문 발췌)

    [출처: kr/근로기준법/법률.md | 현행확인 YYYY-MM-DD]

    ### 관련 판례
    > 【판시사항】 … (원문 발췌)

    [출처: 민사/대법원/대법원_YYYY-MM-DD_사건번호.md]

    ### 적용 논리
    우리 사건 사실관계(근거 표시 유지)에의 적용. 결론 문장.

말미 고정 문구(인용규칙 §4): "본 리서치는 legalize-kr·precedent-kr 저장소 수록
범위 내 검색 결과임. 저장소 외 최신 판례·하급심 판례는 별도 확인 필요."

완료 후 `사건컨텍스트.json`의 `쟁점[].법리ref`를
`리서치/쟁점별_법리.md#쟁점N` 형식으로 채우고, 사용자에게 쟁점별
조문/판례 건수를 보고하며 "검수 후 /draft-complaint 또는 /draft-brief 진행" 안내.

## 철칙

- **Read로 원문을 직접 확인하지 않은 조문·판례는 이 파일에 쓸 수 없다.**
- 발췌 없이 요지만 쓰는 것 금지 — /verify-citations가 발췌로 원본과 대조한다.
- 맞는 판례를 못 찾으면 해당 쟁점에 "판례 미발견 — 조문·해석론으로 구성"이라고
  정직하게 기록한다. 지어내지 않는다.
